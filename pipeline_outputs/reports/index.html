Mathematical Formulation & Pressure Engine

1. Logistic Win Probability (WP) & First-Innings Par Divergence:

WP(s) = 1 / [1 + exp(-(β₀ + β_req·RRR + β_curr·CRR + β_wkt·wickets + β_rem·balls_left))]

2. Continuous Pressure Index (PI in [0, 1]):

PI = 1 - 4·(WP - 0.5)² (calibrated with par-score variance in 1st innings to eliminate leverage collapse)

3. Contextual Ball Value (BV & BoV):

BV = (runs - E[runs]) - 4.5·(wicket - E[wicket])
BoV = -BV = (E[runs] - runs) + 4.5·(wicket - E[wicket])
Clutch Delta (Δ) = Average(Value_pressure) - Average(Value_ordinary)

4. Empirical Bayes Shrinkage Estimator:

θ_shrunk = μ + [ τ² / (τ² + s_i²) ] · (θ_i - μ)

Where τ² represents true between-player variance and s_i² represents individual sampling variance. Regularizes small-sample noise to guarantee statistical reliability across matches.
